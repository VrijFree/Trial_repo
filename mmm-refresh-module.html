Recurring brief patterns

"Where should the next euro go?"

Most common brief across every case above. synthesis

"Is channel X worth it?"

CTV vs linear, social vs search, YouTube/TV return.

"Same budget, better result"

Cassandra, bank and retailer cases.

"Can we trust it?"

Calibration with experiments (Meridian and PyMC-Marketing both support lift-test calibration).

"Build it in-house"

Bolt; Meridian's pitch is in-house teams.

"Show uncertainty"

Everline: decisions with intervals, not point estimates.

Derived from the patterns above. The NL-specific points are synthesis; validate them in conversations with Dutch practitioners.

2Response curves and saturationExplain marginal vs average ROI; identify headroom per channel."Is X worth it?"

5Bayesian priors and uncertainty communicationChoose priors, run prior predictive checks, translate to risk language for a CMO."Show uncertainty"
6Small-market data designNL is a small country, so geo variation is limited; plan national time-series models with informative priors and well-designed tests.Any NL national advertiser

Minimal code to answer "where should the next euro go?" check current docs

# PyMC-Marketing (illustrative; verify against current docs)
from pymc_marketing.mmm import MMM, GeometricAdstock, LogisticSaturation
mmm = MMM(date_column="date", channel_columns=["tv","search","social","ctv"],
          adstock=GeometricAdstock(l_max=8), saturation=LogisticSaturation(),
          control_columns=["price","promo"], yearly_seasonality=2)
mmm.fit(X, y)                                  # Bayesian fit
mmm.add_lift_test_measurements(lift_df)        # calibrate with experiments
mmm.optimize_budget(budget=1_000_000, num_periods=8)   # scenario/optimise
# Meridian (illustrative; verify against current docs)
mmm = model.Meridian(input_data=data, model_spec=spec.ModelSpec())
mmm.sample_prior(500); mmm.sample_posterior(n_chains=4, n_adapt=500, n_burnin=500, n_keep=1000)
optimizer.BudgetOptimizer(mmm).optimize()

One-page decision brief template

  1. Question (client's words).
  2. Answer in one sentence with an interval.
  3. Evidence: response curve, calibration status, decomposition.
  4. Scenarios: flat, +10%, −10%, with constraints.
  5. Risks and next test: what experiment would reduce the uncertainty most.
